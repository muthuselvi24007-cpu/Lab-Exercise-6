# Lab-Exercise-6
Case Study: Zomato Food Delivery Application

A complete practical answer covering solution ideation, user stories, scenario creation, flow mapping, and information architecture.

Solution Ideation
UX Problem: Users want to order food quickly, but may find it difficult to find nearby restaurants, compare food items

and prices, apply filters, and complete checkout efficiently.

Brainwriting / Crazy 8s Ideas:

• Smart Search – Search for food, restaurants or cuisines.

• Nearby Restaurants – Show restaurants based on location.

• Food Categories – Pizza, Biryani, Burger, Chinese, Desserts, etc.

• Filter & Sort – Filter by rating, price, delivery time and veg/non-veg.

• Quick Reorder – Easily order previously purchased food.

• Offers & Coupons – Display available discounts.

• Live Order Tracking – Track delivery status.

• One-Tap Checkout – Complete payment and place the order quickly.

Selected Solution: A quick food-ordering system with search, categories, restaurant listing, filters, cart and simple

checkout.

Creating User Stories
Persona: Priya, 21, college student. Goal: order affordable food quickly from nearby restaurants.

As a user, I want to search for food, so that I can quickly find what I want to eat.

As a user, I want to view nearby restaurants, so that I can choose a convenient restaurant.

As a user, I want to filter restaurants by rating and price, so that I can make a better choice.

As a user, I want to add food items to my cart, so that I can order multiple items together.

As a user, I want to apply coupons, so that I can reduce my total order cost.

As a user, I want to select a payment method, so that I can complete my order easily.

As a user, I want to track my order, so that I know when my food will arrive.

Creating Scenarios

Selected User Story:

“As a user, I want to search for food, so that I can quickly find what I want to eat.” Priya is a college student who feels hungry after class. She opens the Zomato app and wants to order biryani from a nearby restaurant. She searches for “Biryani”. The app displays nearby restaurants with ratings, prices and delivery times. She applies a rating filter, selects a restaurant, chooses Chicken Biryani and adds it to her cart. She checks the total, applies a coupon, selects UPI, confirms her address and places the order.

Emotional States: Hungry fi Curious fi Interested fi Satisfied fi Confident fi Happy

Environment: Mobile phone, college environment, internet connection, and a user who is in a hurry
